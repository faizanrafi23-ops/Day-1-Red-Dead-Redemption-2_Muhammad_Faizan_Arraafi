## Git
Git adalah version control system—yang melacak siapa, kapan, dan apa saja yang sudah dirubah dalam suatu file

## Git workflow
1. Git directory adalah tempat Git menyimpan metadata dan object database dari sebuah proyek.
2. Staging area adalah file yang umumnya berada di dalam direktori Git dan berfungsi untuk menyimpan informasi mengenai perubahan apa saja yang akan dimasukkan ke dalam commit berikutnya.
3. Working directory/tree adalah salinan dari satu versi proyek yang sedang kamu kerjakan

## git vs github
git adalah sistem kontrol yang melacak siapa, kapan, dan apa saja yang diubah dalam suatu file , sedangkan github adalah platform berbasis web yang digunakan untuk menyimpan repository git secara online dan kolaboratif

## Perintah Dasar Git (Essential Git Commands)
Langkah dasar untuk mengelola proyek di komputer lokal:
1. git init: Membuat repository (wadah/lacak perubahan) Git baru di folder proyek kamu.
2. git add .: Memindahkan seluruh file/perubahan ke staging area (area persiapan sebelum disimpan).
3. git commit -m 'pesan': Menyimpan file yang ada di staging area secara permanen ke dalam sistem Git lokal beserta pesan penjelasannya.

## Perintah Git ke GitHub (Remote Commands)
Langkah untuk menghubungkan dan mengirim kode dari komputer lokal ke internet (GitHub):
1. git remote add <nama> <url>: Menghubungkan folder lokal kamu ke repository GitHub di internet.
2. git push origin main: Mengirim (upload) hasil simpanan kode (commit) dari komputer ke GitHub.
3. git pull origin main: Mengambil (download) dan menggabungkan perubahan terbaru dari GitHub ke komputer lokal kamu.
